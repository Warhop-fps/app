# Warhop 브랜드 이미지

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `logo.svg` | 벡터 | 원본. 다른 크기는 모두 이 모양에서 뽑는다 |
| `avatar-500.png` | 500×500 | GitHub 조직 프로필 사진 (Organization settings → Profile picture) |
| `avatar-1024.png` | 1024×1024 | 큰 원본 (발표 자료·문서) |
| `social-preview-1280x640.png` | 1280×640 | 저장소 대표 이미지 (Repository settings → General → Social preview) |
| `favicon.ico` | 16·32·48·64 | 게임 사이트 탭 아이콘 (아직 index.html에 연결 안 함) |
| `apple-touch-icon-180.png` | 180×180 | 휴대폰 홈 화면 아이콘 (아직 연결 안 함) |

색은 게임 화면과 같다: 배경 `#0B0F14`, 강조 `#E8A33D`, 테두리 `#D8E1EA`.
대표 이미지는 생성형 이미지 도구로 만든 시안에서 위쪽 띠와 표시를 잘라 내고 크기를 맞춘 것이다.
